# Фотографии парфюмов

Сюда кладутся готовые снимки флаконов. Пока папка пустая, сайт рисует флаконы
векторной графикой — это запасной вариант, он никогда не ломается.

## Вырезать фон автоматически

Положите исходники в папку `raw-photos/` в корне проекта и запустите:

```bash
npm run cutout -- raw-photos
```

Скрипт (`scripts/cutout.mjs`) сам определит цвет фона по углам кадра, зальёт
его прозрачностью и сложит готовые PNG 1200×1500 сюда, в `public/products/`.

Фон ищется заливкой от краёв кадра, а не порогом «убрать всё светлое». Это
важно: порог съел бы белые буквы на этикетке и светлое стекло, потому что они
тоже светлые. Заливка убирает только то, что связано с границей кадра.

Работает на ровном однотонном фоне — то есть на обычной каталожной съёмке.
Для фотографий в интерьере не подойдёт, там нужен ручной обтравочный контур.

Настройки в начале скрипта: `TOLERANCE` (насколько пиксель может отличаться от
фона), `FEATHER` (мягкость кромки), `PADDING` (воздух вокруг флакона).
Если по контуру остаётся светлый ореол — увеличьте `TOLERANCE` на 5–10.
Если начало «прогрызать» сам флакон — уменьшите.

## Про прозрачное стекло и тёмную тему

Здесь была основная сложность. У стекла нет своего цвета: на съёмке оно
показывает белый фон, и по цвету почти не отличается от него. Обычная заливка
принимает стекло за фон и затекает внутрь флакона — он становится пустым и на
тёмной теме выглядит чёрным пятном с обрывками бликов.

Скрипт решает это в два приёма. Сначала заливка не переходит через контуры
(`EDGE_LIMIT`). Затем силуэт заполняется целиком: для каждой строки берутся
крайние непрозрачные пиксели, для каждого столбца — тоже, и объектом считается
пересечение промежутков. Пересечение, а не объединение, — иначе залилась бы
пустота рядом с кисточками и подвесками.

В итоге стекло сохраняет исходные светлые пиксели и одинаково читается на любом
фоне, а подложка карточки спокойно следует теме.

Если будете снимать сами: ровный светлый фон, флакон целиком в кадре, вертикаль.

## Как подключить готовые файлы

Пропишите пути в `lib/data/products.ts` — в поле `photos` нужного товара:

```ts
{
  slug: "vesper-bloom",
  photos: [
    "/products/vesper-bloom-1.png",
    "/products/vesper-bloom-2.png",
    "/products/vesper-bloom-3.png",
    "/products/vesper-bloom-4.png",
  ],
  // ...
}
```

Всё. Карточка, галерея и корзина сами начнут показывать снимки. Товары без
`photos` продолжат показывать рисованный флакон, так что переходить на фото
можно по одному товару.

Порядок в `photos` = порядок миниатюр в галерее. Первый кадр идёт в карточку
товара и в корзину.

## Права на изображения

Используйте только собственную съёмку или снимки с подходящей лицензией.
Каталожные фотографии чужих марок сюда класть нельзя: на флаконах видны чужие
товарные знаки, и товар получится выдан за свой. Удаление фона этого не меняет —
названия выгравированы на самом стекле.

## Описания для незрячих

Тексты `alt` лежат рядом, в поле `images` того же товара, и не зависят от того,
фото это или рисунок. Если снимок показывает что-то другое — поправьте `alt`
там же.
