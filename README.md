# Eldea

Витрина парфюмерного дома: четырнадцать ароматов для женщин, мужчин и унисекс.
Next.js 16 (App Router), TypeScript, Tailwind CSS v4, Motion, Lenis, Zustand.

```bash
npm install
npm run dev
```

Открыть <http://localhost:3000>.

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Дев-сервер |
| `npm run build` | Продакшен-сборка (33 страницы, все статические) |
| `npm run start` | Запуск собранного проекта |
| `npm run typecheck` | Проверка типов без сборки |
| `npm run cutout -- raw-photos` | Вырезать фон у снимков флаконов |

## Токены и тема

Все цвета живут в `styles/globals.css` как CSS-переменные: `:root` — светлая
тема, `[data-theme="dark"]` — тёмная. Блок `@theme inline` пробрасывает их в
Tailwind, поэтому в компонентах пишется `bg-surface`, `text-muted`,
`border-line`, а не hex-коды. Чтобы перекрасить сайт, достаточно поменять
значения в двух блоках наверху файла.

Тему проставляет маленький скрипт из `components/layout/ThemeToggle.tsx`. Он
выполняется до первой отрисовки и ставит `data-theme` на `<html>` — сохранённый
выбор важнее системного, поэтому тема не мигает при загрузке.

Шрифты подключаются в `app/layout.tsx` через `next/font` с кириллическими
подмножествами: Cormorant Garamond для заголовков, Inter для текста.
Размеры заголовков — утилиты `display-1/2/3` в том же CSS.

## Анимации

Длительности, кривые и пружины заданы один раз в `lib/motion.ts`. В компонентах
не должно быть случайных чисел — берите `transition.standard`, `ease.out`,
`spring` оттуда.

Режим «уменьшить движение» — не заглушка: `respectMotion()` схлопывает варианты
до простого проявления, Lenis не запускается, закреплённая горизонтальная
прокрутка в `NotesStrip` превращается в обычный столбец.

Две вещи, на которые стоит обратить внимание при правках:

- **Lenis нужен `autoRaf: true`.** Без него он перехватывает колесо мыши, но
  не двигает страницу — скролл просто перестаёт работать.
- **`AnimatePresence` не видит выход сквозь фрагмент.** Если внутри него два
  элемента, это должны быть соседи с `key`, иначе они останутся в DOM навсегда.
  Так сделана шторка корзины.

## Каталог

`lib/data/products.ts` — единственное место, откуда сайт берёт товары.
Замените тело `getProducts` / `getProductBySlug` на запрос к API или CMS, и ни
один компонент трогать не придётся.

## Фотографии

Пока фотографий нет, флаконы рисуются вектором: форма и цвет стекла заданы для
каждого аромата в поле `art`. Ничего не зависит от внешних картинок и ничего не
ломается.

Чтобы подключить съёмку — положите исходники в `raw-photos/` и запустите
`npm run cutout -- raw-photos`. Скрипт вырежет фон заливкой от краёв кадра и
сложит готовые PNG 1200×1500 в `public/products/`. Дальше пропишите пути в поле
`photos` нужного товара. Переходить на фото можно по одному.

Отдельная сложность — прозрачное стекло: по цвету оно почти не отличается от
белого фона съёмки, поэтому заливка затекает внутрь флакона и на тёмной теме он
выглядит чёрным. Скрипт не даёт заливке пересекать контуры и затем заполняет
силуэт целиком, так что стекло сохраняет свои светлые пиксели и читается на
любом фоне. Подробности и требования к съёмке:
[`public/products/README.md`](public/products/README.md).

Используйте только собственные или лицензированные снимки — каталожные фото
чужих марок сюда не годятся, на флаконах видны чужие товарные знаки.

## Оформление заказа

Оформление намеренно ненастоящее. Оплата не подключена, шаг с картой принимает
только тестовый номер `4242 4242 4242 4242` и прямо предупреждает, что вводить
настоящие реквизиты не нужно. Ничего не уходит из браузера. Прежде чем ставить
это на реальный домен, замените `PaymentStep` на настоящего провайдера.

Формы контактов и подписки тоже ничего не отправляют — проверяют данные и
показывают подтверждение.

## Доступность

Логотип и иконки — не сгенерированные картинки: логотип это рукописный SVG в
`components/brand/`, иконки берутся из Lucide поштучно. Всё красится через
`currentColor` и переворачивается вместе с темой.

Кроме этого: ссылка «к основному содержанию», видимая рамка фокуса на всех
элементах, ловушка фокуса и закрытие по Escape в шторке и мобильном меню,
минимальный размер кликабельной зоны 44 пикселя. Цвет нигде не единственный
носитель смысла — рейтинг и шкалы интенсивности продублированы числами.
